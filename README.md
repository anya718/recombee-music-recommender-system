Domeniul ales: muzical - date colectate din API-ul public al Spotify
Dataset link: https://www.kaggle.com/datasets/wardabilal/spotify-global-music-dataset-20092025?select=track_data_final.csv

Proprietati alese:
- Numele melodiei - string
- Numele artistului - string
- Popularitatea melodiei - int 
- Durata melodiei in ms - int
- Daca melodia este explicita - boolean
- Data lansarii - timestamp
